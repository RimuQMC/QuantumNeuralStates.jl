QuantumNeuralStates.descent — Function
descent(jacobian_buf, vmc_buf, descent_buf, H, ansatz, addrs_n; kwargs...)
        -> E_mean, variance, last_addr, acceptance, eta_eff

Apply basic gradient descent step for parameter optimisation.

\[\Delta\theta = J \dot \tilde{g}\]

J is pre-sample jacobian (see JacobianBuffer) and g̃ are weighted loss gradients (see apply_loss!).

Arguments

  • jacobian_buf: holds all neccessary variables about jacobians and parameters. See JacobianBuffer.
  • vmc_buffer: holds result from VMC, especially local energies. See VMCBuffer.
  • descent_buf: holds all necessary variables for descent optimisation step. See DescentBuffer.
  • H: hamiltonian defined in Rimu.
  • ansatz: ansatz for evaluation of wave-function. See NeuralAnsatz.
  • addrs_n: newly proposed addresses from VMC. those values are returned for next iteration.

Keyword Arguments

  • vmc: symbol specifying what vmc sampler was chosen (default :metropolis). See vmc_sample!.
  • burnin: number of thermalisation steps in VMC before update (default 100). See vmc_energy.
  • mode: symbol specifying what loss function is applied (default :energy). See apply_loss!.
  • λ: no use here (default 0.001f0).
  • η: learning rate for parameter update (default 0.001f0).

Fields

  • m: 1st moment estimate (exponential moving average of gradients).
  • v: 2nd moment estimate (exponential moving average of squared gradients).
  • Δθ: reusable buffer for the parameter update vector.
  • t: step counter (used for bias correction).
  • β1: decay rate for 1st moment (default: 0.9).
  • β2: decay rate for 2nd moment (default: 0.999).
  • ε: numerical stability term (default: 1e-5).

Notes

Adam: A Method for Stochastic Optimization: https://arxiv.org/pdf/1412.6980.

Stochastic Reconfiguration

QuantumNeuralStates.minSRBuffer — Type
minSRBuffer(N::Int, p::Int, ansatz; kwargs...)

Structure meant for minSR optimiser, see compute_minSR_cg! and minSR. It allows allocation-free, batched and GPU friendly evaluation of minSR and holds the step-control settings of the optimiser.

Variables

  • N: batch size for array dimensions.
  • p: total number of parameters in ansatz model, for array dimensions.
  • ansatz: ansatz model that evaluates wave-function. See also NeuralAnsatz.

Keyword Variables

  • velocity: boolean variable, if true the minSR optimiser will apply momentum smoothening. By default false. See also MomentumBuffer.
  • β: momentum coefficient, used with MomentumBuffer.
  • var_track: running mean of the energy variance, used to detect variance spikes.
  • s_track: running mean of the Jacobian scale s = tr(J̄ᵀJ̄)/N, used to detect sudden drops of s (sample collapse or saturation).
  • d_loose: maximal Fubini–Study distance per step in normal operation (default 1f-1, ≈ 5.7°).
  • d_tight: maximal Fubini–Study distance per step after a variance spike (default 1f-2, ≈ 0.57°). If d_loose < d_tight, d_loose is set to d_tight.
  • ρ: maximal relative weight change η‖Δθ‖/‖θ‖ per step (default 5f-2). During a drop of s the limit is tightened to 0.1*ρ.

Note

  • The Fubini–Study distance measures the overlap of the wave function before and after the update step, cos²(d) = |⟨ψ|ψ'⟩|², so the exact distance lies in [0, π/2]. The value d = η‖J̄ᵀΔθ‖ used here is its linearised estimate on the samples and can exceed π/2 for large steps.
  • The minSR step is derived to first order in the parameter change and is accurate only for d ≪ 1. Sensible values of d_max therefore lie in (0f0, 1f-1].

QuantumNeuralStates.minSR — Function
minSR(jacobian_buf, vmc_buf, minSR_buf, H, ansatz, addrs_n; kwargs...)
        -> E_mean, variance, last_addr, acceptance, eta_eff

One minSR optimisation step: sample, compute the direction Δθ with compute_minSR_cg!, and update the parameters with

\[\theta \leftarrow \theta - \eta_{\mathrm{eff}}\,\Delta\theta, \qquad \eta_{\mathrm{eff}} = \eta \cdot \min\!\left(1,\ \frac{d_{\max}}{d},\ \frac{\mathrm{max\_norm}}{\lVert\Delta\theta\rVert},\ \frac{\rho_{\mathrm{eff}}\,\lVert\theta\rVert}{\eta\,\lVert\Delta\theta\rVert}\right),\]

where d = η ‖J̄ᵀΔθ‖ is the linearised Fubini–Study length of the step on the sampled configurations. The three limits are:

  1. Fubini–Study cap d ≤ d_max: limits the change of the state on the samples. d_max = d_tight after a variance spike, otherwise d_loose.
  2. Euclidean backstop ‖Δθ‖ ≤ max_norm: guard against non-finite or divergent updates.
  3. Relative weight cap η‖Δθ‖ ≤ ρ_eff ‖θ‖: limits the change of the network as a whole, including configurations outside the sample set (e.g. the neighbours entering E_loc). ρ_eff = 0.1*ρ during a drop of s, otherwise ρ.

The Fubini–Study cap and the relative cap are complementary: when the samples respond only weakly to the parameters (small s), d underestimates the size of the step and the relative cap binds; when they respond strongly (large s), the Fubini–Study cap binds.

Arguments

  • jacobian_buf: Jacobian and parameter vector θ, see JacobianBuffer.
  • vmc_buf: VMC results (local energies), see VMCBuffer.
  • minSR_buf: minSR and CG buffers, see minSRBuffer.
  • H: Rimu Hamiltonian.
  • ansatz: see NeuralAnsatz.
  • addrs_n: current walker addresses; the updated ones are returned.

Keyword Arguments

  • vmc: sampler, :metropolis or :ctmc (default :metropolis), see vmc_sample!.
  • burnin: thermalisation steps before the update (default 100), see vmc_energy.
  • mode: loss mode (default :energy), see apply_loss!.
  • λ: Tikhonov shift, relative to the mean eigenvalue of J̄ᵀJ̄ (default 1f-3).
  • η: learning rate / imaginary-time step (default 1f-3).
  • max_norm: Euclidean backstop on ‖Δθ‖ (default 1f3).

Notes

  • Variance spike: the variance exceeds 10× its running mean (var_track). The Fubini–Study cap is tightened to d_tight.
  • Drop of s: s falls below 1/100 of its running mean (s_track), tolerated for up to max_spike = 20 consecutive steps. This indicates that the walkers concentrate on few configurations, so the update direction carries little information while the weights can still change considerably; the relative cap is tightened to 0.1 ρ.
  • The Fubini–Study cap follows the natural norm constraint, see DOI: 10.1016/j.jcp.2024.113351 (Sec. 3.1). The relative cap follows layer-wise trust ratios (arXiv:1708.03888) and deep relative trust (arXiv:2002.03432).
  • The step is skipped (parameters unchanged) if the solve fails or d or ‖Δθ‖ is non-finite.
  • Momentum, if enabled, is applied before d is measured.

QuantumNeuralStates.cg_solve! — Function
cg_solve!(x, J_bar, λ, r, p_vec, Ap, tmp; kwargs...) -> (ok, iters, relres)

Conjugate-gradient solver for the minSR system, GPU-friendly and allocation-free,

\[(\bar{J}^T \bar{J} + \lambda \mathbf{I})\, x = b,\]

with b passed in r and initial guess x = 0. Expects the system pre-scaled by the caller (mean eigenvalue of J̄ᵀJ̄ ≈ 1, ‖b‖ = 1), so λ and null_tol are relative.

Arguments

  • x: (N,) solution, written in place.
  • J_bar: (p, N) weighted, centred, rescaled Jacobian.
  • λ: relative Tikhonov shift.
  • r: (N,) RHS b on input, residual on output.
  • p_vec, Ap: (N,) CG buffers.
  • tmp: (p,) scratch buffer.

Keyword Arguments

  • max_iter: maximum iterations (default 300).
  • tol: relative residual ‖r‖/‖b‖ for convergence (default 1f-2).
  • null_tol: null-space threshold on pᵀKp / pᵀp (default 1f-6).
  • max_null_hits: null-space restarts before stopping (default 3).

Returns

  • ok: true if x is usable (converged, max_iter, or null-space stop); false on numerical breakdown (Inf/NaN), in which case the step must be skipped.
  • iters: iterations performed.
  • relres: ‖r‖/‖b‖ at exit.

Null-space guard

K = J̄ᵀJ̄ is singular by construction (centring) and rank-deficient for duplicate configurations. Directions with pᵀKp < null_tol · pᵀp (with pᵀKp = ‖J̄p‖² from the matvec) are skipped by restarting p from the residual; after max_null_hits the solve stops with the current partial solution.

Notes

Reference: J. R. Shewchuk, An Introduction to the Conjugate Gradient Method Without the Agonizing Pain, https://people.eecs.berkeley.edu/~jrs/papers/cg.pdf (p. 32).

QuantumNeuralStates.compute_minSR_cg! — Function
compute_minSR_cg!(E_mean, variance, jacobian_buf, vmc_buf, minSR_buf,
                  ansatz, mode, λ, weights) -> (Δθ, sq, ok)

Compute the minSR natural-gradient direction with the matrix-free cg_solve!,

\[\Delta\theta = \bar{J}\, (\bar{J}^T \bar{J} + \lambda_{\mathrm{abs}} \mathbf{I})^{-1}\, b , \qquad \lambda_{\mathrm{abs}} = s\,\lambda ,\]

where J̄[:, b] = √w_b (O_b − Ō) is the weighted, centred Jacobian and b the weighted loss gradient vector from apply_loss!. The system is solved in rescaled form (J' = J̄/√s, b' = b/‖b‖, s = tr(J̄ᵀJ̄)/N), so λ is relative to the mean eigenvalue and all CG quantities are O(1).

The solution is mapped back as Δθ = (‖b‖/√s) J'x'.

Arguments

  • E_mean: (1,) device arrays with ⟨E_loc⟩.
  • variance: (1,) device arrays with σ².
  • jacobian_buf: holds the Jacobian J (n_params, N).
  • vmc_buf: holds E_locs (N,); ham_diag is reused for b gradients.
  • minSR_buf: CG and update buffers, see minSRBuffer.
  • ansatz: see NeuralAnsatz.
  • mode: loss mode for apply_loss!.
  • λ: relative Tikhonov shift.
  • weights: (N,) normalised sampler weights (Σw = 1), see vmc_sample!.

Returns

  • Δθ: (n_params,) update direction.
  • sq: √s, needed by the minSR for the Fubini–Study step length and the detection of drops of s.
  • ok: false if s, ‖b‖ or the CG solve is invalid; the minSR must skip the step.
