QuantumNeuralStates._prepare_input_stream_kernel! — Function
_prepare_input_stream_kernel!(xe, addrs, offsets, offset_current, ch, f, s)

Kernel that fills the network input for one forward pass. Launched with ndrange = n, one thread per input column j. Thread j takes stream position g = offset_current + j, finds its slot (k, b) with _find_column and _column_start, and writes the scaled occupations f(onr(addrs[k, b])) * s into xe[:, ch, j].

Variables

  • xe: network input viewed as xe[m, c, j] (site, channel, batch position).
  • addrs: off-diagonal addresses (K, B).
  • offsets: cumulative valid counts per column, length B.
  • offset_current: stream positions processed by earlier passes.
  • ch: occupation channel of the input encoding.
  • f, s: input_scale_func and normalisation of the NeuralAnsatz.

See multi_compute_logψ! for the meaning of the indices.

QuantumNeuralStates.solve_self_consistent_eta — Function
solve_self_consistent_eta(h::Rimu.FroehlichPolaron; tol = sqrt(eps(T)), max_iter = 500)
        -> (eta, f)

Solve the Lee–Low–Pines self-consistency for the phonon momentum fraction η by fixed-point iteration. The phonon momentum of the coherent state must equal the fraction η of the total momentum,

\[\eta\,\mathbf{P} = \sum_k \mathbf{k}\, f_k^2 \quad\Longrightarrow\quad \eta = \frac{1}{P^2}\sum_k (\mathbf{k}\cdot\mathbf{P})\, f_k^2(\eta) ,\]

with f_k(η) from calc_f.

Arguments

  • h: Froehlich polaron Hamiltonian.

Keyword Arguments

  • tol: relative convergence tolerance on η (default sqrt(eps(T)), ≈ 3.5e-4 for Float32 and ≈ 1.5e-8 for Float64).
  • max_iter: maximal number of fixed-point iterations (default 500).

Returns

  • eta: converged phonon momentum fraction.
  • f: (M,) f_k(η) at the converged η.

Notes

  • For P = 0 there is no preferred direction, so η = 0 by symmetry and no iteration is performed.
  • If the iteration does not converge within max_iter, a warning is issued and the last iterate is returned.

References

  • T. D. Lee, F. E. Low, D. Pines, Phys. Rev. 90, 297 (1953).
  • arXiv:1510.04934.
source
QuantumNeuralStates.calc_omega_denominator — Function
calc_omega_denominator(h::Rimu.FroehlichPolaron, kidx::Int, eta) -> ε_k

Energy denominator of the Lee–Low–Pines mean-field for phonon mode kidx,

\[\varepsilon_k = \omega + \frac{k^2}{2m} - \frac{\mathbf{k}\cdot\mathbf{P}}{m}\,(1 - \eta), \qquad m = \frac{\texttt{two\_m}}{2},\]

where P = h.p is the total momentum and η the fraction of P carried by the phonons, P_ph = η P (see solve_self_consistent_eta).

Arguments

  • h: Froehlich polaron Hamiltonian.
  • kidx: index of the phonon mode, h.ks[kidx].
  • eta: phonon momentum fraction η.

See also calc_f.

QuantumNeuralStates.calc_f — Function
calc_f(h::Rimu.FroehlichPolaron, eta) -> f

Coherent-state displacements of the Lee–Low–Pines mean-field,

\[f_k = \frac{v_k}{\varepsilon_k},\]

with the coupling v_k from Rimu.Hamiltonians.calc_vk and the denominator ε_k from calc_omega_denominator. The sign follows the convention H = … − Σ_k v_k (a_k^† + a_k).

Arguments

  • h: Fröhlich polaron Hamiltonian.
  • eta: phonon momentum fraction η.

Returns

  • f: (M,) one f_i per phonon mode; f_k = 0 for modes with v_k = 0 (the k = 0 mode).

Notes

  • Throws an error if ε_k ≤ 0 for any mode. The mean-field is then beyond its range of validity (the total momentum is too large for a bound polaron within this ansatz).

strong_coupling_amplitudes(h::Rimu.FroehlichPolaron) -> β

Strong-coupling coherent amplitudes, Eq. (4.6) - Yosef:

  • h: Froehlich polaron Hamiltonian, with coupling constant h.alpha.

Returns

  • β: (M,) amplitudes, one per phonon mode; β_k = 0 for modes with V_k = 0 (the k = 0 mode).

Notes

  • Not used by MeanField at the moment; the weak-coupling Lee–Low–Pines displacements from solve_self_consistent_eta are used instead.

QuantumNeuralStates._mf_func_froehlich — Function
_mf_func_froehlich(o, params, T) -> T

Log-amplitude of the Froehlich coherent-state mean-field for occupation numbers o,

\[\log\psi_{\mathrm{MF}}(n) = \sum_i n_i \log|f_i| - \tfrac{1}{2}\sum_i \log(n_i!) - \tfrac{1}{2}\sum_i f_i^2 .\]

Arguments

  • o: occupation numbers onr(addr) of one configuration.
  • params: (log_f, lgf, const_term) from _choose_meanfield_function, where lgf[n+1] = log(n!) is a look-up table and const_term = -0.5 Σ f².
  • T: element type of the result.

Notes

  • Occupations with n ≥ length(lgf) use the Stirling formula log(n!) ≈ n log n − n + ½ log(2πn) + 1/(12n).
  • Called inside _mf_addrs_kernel! and _mf_offdiag_kernel!.
