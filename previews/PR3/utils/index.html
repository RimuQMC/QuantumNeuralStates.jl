QuantumNeuralStates.memory_estimate — Function
memory_estimate(x) -> Int

Estimate the memory (in bytes) held by all arrays (only) reachable from x, searching struct fields, tuples, and named tuples recursively. Works for CPU and GPU arrays. Assumes every array is referenced only once.

QuantumNeuralStates.GPUGrowColumnBuffer — Type
GPUGrowColumnBuffer(backend, T, fixed, init_capacity)
GPUGrowColumnBuffer(backend, T, init_capacity)          # 1D

Device buffer of shape (fixed..., capacity). The LAST dimension capacity grows, all leading dimensions are fixed. Typical use: network outputs (n_out, n).

ensure_capacity!(buf, n) guarantees capacity ≥ n and returns the full buf.data. The valid part is chosen by the caller, e.g. view(buf.data, :, 1:n). Growing does not preserve old contents.

QuantumNeuralStates.ensure_capacity! — Function
ensure_capacity!(buf, total) -> data

Make sure the growing dimension of buf has room for at least total entries, and return the full device array buf.data.

  • GPUGrowColumnBuffer: the LAST dimension grows, size(data) = (fixed..., capacity).
  • GPUGrowRowBuffer: the FIRST dimension grows, size(data) = (capacity, fixed...).

If total > buf.capacity, a new array with capacity = ceil(1.2 * total) is allocated on the same backend and the old one is freed. Otherwise nothing happens.

Arguments

  • buf: GPUGrowColumnBuffer or GPUGrowRowBuffer.
  • total: required size of the growing dimension.

Returns

  • data: the full array buf.data, including unused capacity. The caller selects the valid part, e.g. view(data, :, 1:total) or view(data, 1:counts[b], b).

Notes

  • Growing does NOT preserve old contents; fill the buffer after calling ensure_capacity!.
  • The capacity only grows, never shrinks. The 20% margin avoids reallocating on every small increase.
  • After growing, the old array is released with KernelAbstractions.unsafe_free!. Any reference or view to the previous buf.data kept elsewhere becomes invalid, so always use the returned array (or re-read buf.data) after the call.

QuantumNeuralStates.set_centering! — Function
set_centering!(ansatz; first=false)

Set ansatz.logψ_centering to the maximum of the network output for log ψ, and return it.

The output of the neural network for log ψ can drift by an arbitrary constant during training, since the normalization of the wavefunction is not fixed. Subtracting this centering value keeps the values in a numerically safe range, for example to avoid overflow in exp(logψ).

Keyword arguments

  • first::Bool=false: if true (initialization, or after loading weights), the centering is computed from compute_logψ at the starting address of ansatz.hamiltonian. If false - default (inside the training loop), it is computed by re-evaluating ansatz.model on the last input cached in ansatz.model.x.

Returns

  • The new value of ansatz.logψ_centering.
