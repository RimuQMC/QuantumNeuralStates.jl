Variational Monte Carlo

VMC

QuantumNeuralStates.VMCBuffer — Type
VMCBuffer(ansatz, addr; K_init = nothing)

This structure holds all intermediate variables of a VMC step. All buffers live on the device of ansatz.model (CPU or GPU), except accepted and the host scratch median_cpu.

Variables

  • ansatz: NeuralAnsatz.
  • addr: Rimu address, used for the address type and to initialise address buffers.

Keyword Arguments

  • K_init: initial number of off-diagonal slots per sample. Defaults to the global estimate num_offdiagonals(ansatz.hamiltonian) if available, otherwise to num_offdiagonals(ansatz.hamiltonian * addr). This is only a starting guess; the off-diagonal buffers grow automatically if a sample has more connections.

QuantumNeuralStates.collect_offdiagonals! — Function
collect_offdiagonals!(addrs_buf, hmn_buf, diag, offsets, hamiltonian, addrs_n, mask)

Collect, on the device, the diagonal element and all valid off-diagonal connections of every address in addrs_n.

Column b of addrs_buf.data and hmn_buf.data receives the off-diagonal addresses and offdiagonal matrix elements of parent b; diag[b] its diagonal element; offsets the cumulative sum of number of offdiagonals. Off-diagonals with a zero matrix element, and (if mask !== nothing) those violating the truncation, are skipped.

If any parent has more off-diagonals than the current number of rows K (in addrs_buf or hmn_buf), both row buffers are grown to fit the largest count and the collection is repeated, so no connection is ever lost. The grown size is kept for later calls.

Variables

  • addrs_buf: GPUGrowRowBuffer of addresses, (K, B).
  • hmn_buf: GPUGrowRowBuffer of Float32 matrix elements, (K, B).
  • diag: (B,) receives the diagonal elements.
  • offsets: (B,) Int32 device vector, receives cumsum(num_offdiagonals).
  • hamiltonian: Rimu Hamiltonian; has to be Float32/isbits compatible.
  • addrs_n: (B,) vector of the current addresses.
  • mask: truncation mask on the device, or nothing for no truncation. See also TruncationBuffer.

CTMC

QuantumNeuralStates.ctmc_sample! — Function
ctmc_sample!(vmc_buf, jacobian_buf, hamiltonian, addrs_n, ansatz; eclamp=true)
    -> new_addrs, E_locs, weights, grads_n, acc

Perform one step of the lazy Continuous-Time Monte Carlo (CTMC) sampler for VMC.

For each walker n in the batch, new configurations are proposed only among its off-diagonal connections $m$ with $H_{nm} \neq 0$ (optionally restricted by the truncation mask of ansatz). The target m is selected according to jump rates built from the wave-function amplitudes log|ψ(m)|.

In CTMC, a walker always jumps to the proposed state. To compensate, each sample carries a residence time: the weight describing how long the walker effectively stays on configuration n before jumping. See get_ctmc_weights!.

Lazy chain

A pure jump chain can be periodic. For example, with particle-number or bipartite structure it can alternate between two sublattices forever, which breaks ergodicity of the Markov chain. To make the chain aperiodic, the sampler is lazy: each walker moves to its proposed state with probability 0.75 and stays at n with probability 0.25. The stationary distribution is unchanged.

Arguments

  • vmc_buf: VMCBuffer holding intermediate variables for allocation-free calculations.
  • jacobian_buf: JacobianBuffer used to compute the per-sample Jacobians.
  • hamiltonian: Hamiltonian defined in Rimu.
  • addrs_n: current walker addresses (length = batch size B). Updated in place.
  • ansatz: wave-function ansatz, see NeuralAnsatz.

Keywords

  • eclamp::Bool=true: clip outlying local energies, see calculate_local_energy! and elocs_clamping!.

Returns

  • new_addrs: (B,) next walker positions (the same array as addrs_n).
  • E_locs: (B,) local energies of the configurations n.
  • weights: (B,) CTMC residence-time weights.
  • grads_n: (p, B) per-sample gradients of log ψ(n), or nothing if vmc_buf.start is false.
  • acc: fraction of walkers that moved, in [0, 1].

All arrays live on the same device (CPU/GPU) as the inputs.

Note

When vmc_buf.start is false (e.g. during burn-in), only the walkers are advanced. In that case E_locs and weights are not computed, and their contents are meaningless.

QuantumNeuralStates.ctmc_state_proposal! — Function
ctmc_state_proposal!(addrs_m, addrs_m_all, offsets, distro, rand_vals)

This function proposes a new address for every spawning address in a CTMC sampler step. From each spawning address b all valid off-diagonal connections are collected in column b of addrs_m_all; the new address is drawn among them with probability proportional to exp(distro), by inverse-CDF sampling. The chosen address is written directly into addrs_m[b] on the device.

For numerical stability the maximum of distro over each parent's off-diagonals is subtracted before exponentiating, so every term is ≤ 1 and the largest is exactly 1.

Variables

  • addrs_m: (B,) device vector, receives the proposed address of each parent.
  • addrs_m_all: (K, B) off-diagonal addresses; column b belongs to parent b.
  • offsets: device vector of length B, cumulative number of valid off-diagonals per parent. Parent b owns stream positions _column_start(offsets, b) + 1 : offsets[b].
  • distro: log-weights of all valid off-diagonals, packed in stream order (length last(offsets)). For example logψ of the off-diagonals for ψ-weighted proposals, or zeros for uniform proposals.
  • rand_vals: (B,) device buffer, refilled with uniform random numbers in [0, 1).

Note

A parent without off-diagonals leaves addrs_m[b] unchanged.

QuantumNeuralStates.get_ctmc_weights! — Function
get_ctmc_weights!(weights, log_distro, offsets, log_psi) -> weights

This function calculates the normalised CTMC holding-time weights of the batch,

\[w_b = \frac{|\psi(n_b)|}{\sum_m |\text{exp(log_distro)}(m_b)|}\]

where the sum runs over the valid off-diagonals m of parent b, and log_distro holds log_psi_m, the same as used in ctmc_state_proposal!.

Variables

  • weights: (B,) device vector, receives the normalised weights (Σ_b w_b = 1).
  • distro: log amplitudes of all valid off-diagonals, packed in stream order (length last(offsets)), same as in ctmc_state_proposal!.
  • offsets: device vector of length B, cumulative number of valid off-diagonals per parent. Parent b owns stream positions _column_start(offsets, b) + 1 : offsets[b].
  • log_psi: (B,) log amplitudes of the current samples, see log_psi!.

Note

A parent without off-diagonals gets weight 0.

Metropolis

QuantumNeuralStates.metropolis_sample! — Function
metropolis_sample!(vmc_buf, jacobian_buf, hamiltonian, addrs_n, ansatz; eclamp=true)
    -> new_addrs, E_locs, weights, grads_n, acc

Perform one step of the Metropolis–Hastings (MCMC) sampler for VMC.

For each walker n in the batch, a new configuration m is proposed uniformly at random among the off-diagonal connections of n, i.e. the configurations with $H_{nm} \neq 0$, optionally restricted by the truncation mask of ansatz. The proposal is accepted with probability

\[A(m|n) = \min\left(1, \frac{|\psi(m)|^2}{|\psi(n)|^2} \frac{N_n}{N_m}\right),\]

where $N_n$ and $N_m$ are the numbers of valid off-diagonal connections of n and m. The factor $N_n/N_m$ is the Hastings correction for the uniform proposal $q(m|n) = 1/N_n$. It ensures detailed balance with respect to $|\psi|^2$ even when configurations have different numbers of connections.

The exponent of the amplitude ratio is clamped to [-80, 80] before exp() to avoid Float32 overflow. Rejected proposals keep the walker in place, so the chain is aperiodic without an explicit lazy step (compare ctmc_sample!).

Arguments

  • vmc_buf: VMCBuffer holding intermediate variables for allocation-free calculations.
  • jacobian_buf: JacobianBuffer used to compute the per-sample Jacobians.
  • hamiltonian: Hamiltonian defined in Rimu.
  • addrs_n: current walker addresses (length = batch size B). Updated in place.
  • ansatz: wave-function ansatz, see NeuralAnsatz.

Keywords

  • eclamp::Bool=true: clip outlying local energies, see calculate_local_energy! and elocs_clamping!.

Returns

  • new_addrs: (B,) next walker positions (the same array as addrs_n).
  • E_locs: (B,) local energies of the configurations n before the move.
  • weights: (B,) uniform weights 1/B.
  • grads_n: (p, B) per-sample gradients of log ψ(n), or nothing if vmc_buf.start is false.
  • acc: acceptance rate over the batch, in [0, 1].

All arrays live on the same device (CPU/GPU) as the inputs.

Note

When vmc_buf.start is false (e.g. during thermalization), only the walkers are advanced. In that case E_locs and weights are not computed: E_locs holds the random acceptance draws and weights keeps its previous contents.

Local Energy

QuantumNeuralStates.vmc_energy — Function
vmc_energy(H, ansatz, addrs_n, vmc_buf, jacobian_buf; kwargs...)
    -> E_mean, variance, addrs_n, acceptance, weights

Estimate the variational energy $\langle H \rangle_\psi$ with Variational Monte Carlo (VMC).

The batch of B walkers in addrs_n is treated as B independent Markov chains. They are first thermalised for burnin steps. Then one more sampling step evaluates the local energies and per-sample gradients, which are reduced to the weighted mean and variance. Type of sampling is decided in vmc_sample!.

Arguments

  • H: Hamiltonian defined in Rimu.
  • ansatz: wave-function ansatz, see NeuralAnsatz.
  • addrs_n: batch of walker addresses (Rimu Fock-state representation).
  • vmc_buf: pre-allocated VMCBuffer.
  • jacobian_buf: pre-allocated JacobianBuffer for the per-sample Jacobians. It holds the gradients of the last sampling step on return.

Keyword Arguments

  • vmc_sampler::Symbol=:metropolis: sampler, :metropolis or :ctmc.
  • burnin::Integer=100: number of thermalisation steps before samples are collected.
  • mode::Symbol=:energy: minimisation mode (loss function). Currently unused.
  • eclamp::Bool=true: clip outlying local energies, see elocs_clamping!.

Returns

  • E_mean: weighted mean of the local energies, $\langle E_{loc} \rangle$.
  • variance: weighted variance of the local energies, $\sigma^2(E_{loc})$.
  • addrs_n: final walker positions (the same array as the input addrs_n).
  • acceptance: fraction of walkers that moved in the last step, in [0, 1]. For Metropolis this is the acceptance rate. For lazy CTMC it is about 0.75.
  • weights: (B,) per-sample weights used in the averages.

Notes

  • Thermalisation: during the burnin steps only the walkers move. Local energies and gradients are not computed, which keeps burn-in cheap.
  • Weights: Metropolis weights are uniform (1/B). CTMC weights are residence times, see get_ctmc_weights!.
  • Sanity checks: an error is thrown if the local energies or gradients contain NaN/Inf.

Example

E, var, addrs, acc, w = vmc_energy(H, ansatz, addrs_n, vmc_buf, jac_buf;
                                   vmc_sampler=:ctmc, burnin=50, eclamp=true)

QuantumNeuralStates.local_energy_stats! — Function
local_energy_stats!(vmc_buf, E_locs, weights, batch) -> (E_mean, variance)

Compute the weighted mean and variance of the local energies,

\[\langle E \rangle = \sum_i w_i\, E_{\mathrm{loc},i}, \qquad \sigma^2 = \sum_i w_i \left(E_{\mathrm{loc},i} - \langle E \rangle\right)^2 ,\]

on the backend of E_locs. The results are written into vmc_buf.E_mean and vmc_buf.variance, both (1,) device arrays.

Arguments

  • vmc_buf: holds the output buffers E_mean and variance, see VMCBuffer.
  • E_locs: (batch,) local energies.
  • weights: (batch,) sampler weights, normalised to Σw = 1.
  • batch: number of samples.

QuantumNeuralStates.calculate_local_energy! — Function
calculate_local_energy!(ansatz, vmc_buf, n_logψ, n_sign, m_logψ, m_sign; eclamp=true)

Calculate the local energies of a VMC batch in place, storing them in vmc_buf.E_locs.

The function dispatches on the AnsatzType of ansatz, since different wave-function representations may require different ways of evaluating

\[E_{loc}(n) = H_{nn} + \sum_{m \neq n} H_{nm} \frac{\psi(m)}{\psi(n)},\]

where the amplitude ratio is computed from log-amplitudes and signs as $\psi(m)/\psi(n) = s(m)\,s(n)\,\exp(\log|\psi(m)| - \log|\psi(n)|)$. The exponent is clamped to the Float32 range before exp() to avoid overflow.

All intermediate quantities live in vmc_buf, so the calculation is allocation-free.

Arguments

  • ansatz: wave-function ansatz, see NeuralAnsatz.
  • vmc_buf: buffer for VMC calculations, see VMCBuffer.
  • n_logψ: vector of log|ψ(n)| for the sampled configurations n.
  • n_sign: signs of ψ(n), as a vector or a single number.
  • m_logψ: vector of log|ψ(m)| for the connected configurations m.
  • m_sign: signs of ψ(m), as a vector or a single number.

Keyword Arguments

  • eclamp::Bool=true: clip outlying local energies with elocs_clamping! after they are computed.

Returns

nothing; the result is written to vmc_buf.E_locs.

Note

Clipping counters node-like instabilities, where $\psi(n) \approx 0$ makes the ratio blow up. These occur not only at true nodes of the wave function but also with a not-yet-trained neural network, whose output can resemble a node.

source
QuantumNeuralStates.elocs_clamping! — Function
elocs_clamping!(E_locs, median_cpu) -> E_locs

Clamp outliers of the local energies in place to the window median ± n_q · Q_q(|E_loc − median|), where Q_q is the q-quantile of the distances from the median.

Arguments

  • E_locs: (B,) device vector of local energies, overwritten with clipped values.
  • median_cpu: (B,) host buffer; its contents are overwritten and reordered.

Keyword Arguments

  • q: quantile that defines the spread (default 0.99; use 0.95 for small batches).
  • n_q: window width in units of that spread (default 10).

Note

median! and quantile! are not GPU-supported and run on the CPU copy, which is faster than the GPU for arrays of this size.

QuantumNeuralStates.final_elocs_statistics! — Function
final_elocs_statistics!(vmc_sampler, vmc_buf, jac_buf, H, addrs, ansatz;
                        n_iter=100, n_skip=5, burnin=50,
                        plot_occ=true, occ_file="occupation.png")
    -> res, N_all, counts, n_mode

Estimate the variational energy of the trained NeuralAnsatz with an error bar, and record the occupation statistics of the sampled walkers. Run at the end of run_training_loop.

Starting from the last walker addresses addrs of the training loop, the sampler is first re-equilibrated for burnin steps. It then records n_iter measurements, separated by n_skip sampler steps each. Every measurement is the weighted batch mean

\[E_t = \sum_{b=1}^{B} w_b\, E_{\mathrm{loc}}(n_b), \qquad \sum_{b=1}^{B} w_b = 1,\]

and the time series $E_t$ is analysed with Rimu.blocking_analysis, which accounts for the autocorrelation between measurements. In total n_iter * B local energies are used.

Local energies are never clipped here (eclamp=false), so the estimate is unbiased.

Arguments

  • vmc_sampler: sampler type, :metropolis or :ctmc, see vmc_sample!.
  • vmc_buf: VMC buffers, see VMCBuffer.
  • jac_buf: Jacobian buffer, see JacobianBuffer.
  • H: Rimu Hamiltonian.
  • addrs: walker addresses at the end of training. Updated in place.
  • ansatz: the trained NeuralAnsatz.

Keyword Arguments

  • n_iter: number of measurements (default 100).
  • n_skip: sampler steps per measurement. The n_skip - 1 steps in between are made without measuring, to reduce correlations. n_skip ≤ 1 measures every step (default 5).
  • burnin: re-equilibration steps before the first measurement (default 50).
  • plot_occ: if true, plot the occupation statistics (default true).
  • occ_file: file name for the occupation plots (default "occupation.pdf").

Returns

  • res: result of Rimu.blocking_analysis, with the mean energy and its error estimate.
  • N_all: total occupation N of every measured walker sample (n_iter * B entries).
  • counts: Dict{Int, Int} with the number of walker samples for each total occupation N.
  • n_mode: (M,) average occupation of each mode over all walker samples.

Notes

  • The error bar from the blocking analysis is the reliable one. The E_err printed during training is computed per block without this correlation analysis and can be too small.
  • If plot_occ = true, two bar plots are saved to occ_file: the number of walker samples per total occupation N (log scale) and the average occupation per mode.
  • The mean-field, if present in ansatz, is included automatically through the samplers.
  • ansatz.neuron_statistics and ansatz.jacobian_statistics are set to false and are not restored.
  • With few measurements (small n_iter), the blocking analysis may not converge. Increase n_iter if res reports this.
